# КАМДЕТАЛЬ

Адаптивный интерфейс интернет-магазина запчастей для КАМАЗ: каталог с поиском по артикулам и OEM, оформление заказов, личный кабинет и административная панель. Промышленная типографика, графитовые оттенки и оранжевые акценты формируют визуальный стиль; навигация и основные сценарии адаптированы для мобильных устройств.

[Открыть магазин](https://kamdetal-storefront.vercel.app/) · [Демо административной панели](https://kamdetal-storefront.vercel.app/admin)

## Статус проекта

Функциональная frontend-демоверсия на React и TypeScript. Встроенный каталог содержит 15 товаров в 6 категориях. Корзина, заказы, профиль и изменения контента сохраняются в `localStorage` текущего браузера.

Серверная часть и внешние интеграции находятся за пределами текущей реализации. План подключения Laravel описан в [технической документации](docs/backend-handoff.md).

## Возможности

| Раздел | Функциональность |
| --- | --- |
| Главная страница | Категории, подборки товаров, редактируемые баннеры, поиск по артикулу, подбор по модели и группе, заявка на подбор по VIN |
| Каталог | Поиск по названию, артикулу, OEM и производителю; фильтры по цене, наличию, модели и бренду; сортировка, плитка и список |
| Карточка товара | Галерея, интерактивный 3D-просмотр при наличии модели, характеристики, применяемость, выбор количества, избранное, покупка в один клик, условия доставки и гарантии |
| Корзина и заказ | Пересчёт стоимости, оформление для физических лиц, ИП и организаций, реквизиты, выбор способа доставки |
| Личный кабинет | Профиль покупателя, история и статусы заказов, просмотр и печать состава заказа |
| Административная панель | Редактирование товаров, обработка заказов, импорт прайсов, управление текстами и баннерами главной страницы |
| Интерфейс | Мобильная навигация, анимации при прокрутке и добавлении в корзину, поддержка `prefers-reduced-motion` |
| Метаданные | Динамические Title и Description, структурированные данные Product и BreadcrumbList |

## Технологии

- **React 19, TypeScript 5.8** — компоненты и типизация.
- **Vite 6** — локальная разработка и сборка.
- **React Router 7** — клиентская маршрутизация.
- **CSS, Web Animations API** — адаптивная вёрстка и анимации.
- **PapaParse, read-excel-file** — обработка CSV и XLSX.
- **Lucide React** — иконки.
- **Playwright** — браузерные проверки.
- **Three.js** — просмотр 3D-моделей с загрузкой по запросу.

### 3D-просмотр

Модели восстанавливаются из фотографий товаров с помощью AI и открываются в отдельном окне с вращением, масштабированием и управлением с клавиатуры. Это визуальные реконструкции: форма и скрытые поверхности могут отличаться от оригинала. Инструкции по генерации и добавлению моделей — в [документации 3D-просмотра](docs/product-3d.md).

## Локальный запуск

Требуется Node.js 20.19+ и npm.

```sh
git clone https://github.com/pyaidev/kamaz.git
cd kamaz
npm ci
npm run dev -- --port 4173
```

Магазин доступен по адресу `http://127.0.0.1:4173`, административная панель — `http://127.0.0.1:4173/admin`.

### Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск сервера разработки |
| `npm run build` | Проверка TypeScript и сборка в `dist/` |
| `npm run preview -- --port 4173` | Локальный просмотр готовой сборки |
| `npm test` | Запуск тестов Playwright |

## Импорт прайсов

Административная панель поддерживает CSV в UTF-8 с автоматическим определением разделителя и XLSX с чтением первого листа. Перед применением доступна проверка данных. Лимит одного файла — 10 МБ и 15 000 строк данных.

[Шаблон CSV](public/price-template.csv)

| Колонка | Английское имя | Требование |
| --- | --- | --- |
| Артикул | `article` | Обязательная; значения с ведущими нулями следует хранить как текст |
| Название | `name` | Обязательная |
| Цена | `price` | Обязательная; положительное число |
| Остаток | `stock` | Обязательная; целое неотрицательное число |
| Производитель | `brand` | Обязательная |
| Категория | `category` | Необязательная; должна соответствовать категории каталога |

Существующие позиции сопоставляются по нормализованной паре «артикул + производитель». Дубликаты и некорректные значения блокируют применение файла. Товары, отсутствующие в прайсе, сохраняются без изменений.

Если категория не указана, существующий товар сохраняет свою категорию, а новый добавляется в «Двигатель». Новые позиции получают иллюстрацию категории; фотографии и характеристики можно уточнить в редакторе товаров.

## Подключение серверной части

Для коммерческой эксплуатации требуется реализовать:

- API и базу данных, серверную пагинацию и фоновую обработку прайсов.
- Авторизацию покупателей и разграничение доступа к административной панели.
- Синхронизацию цен и остатков с поставщиком или учётной системой.
- Формирование счетов с реквизитами продавца и подтверждение оплаты.
- Интеграцию со СДЭК для получения тарифов и оформления отправлений.
- Отправку уведомлений и серверную подготовку страниц для индексации.

В демоверсии административная панель открыта без авторизации, расчёт доставки использует примерные значения, а печатная форма содержит состав заказа. Данные сохраняются только в текущем браузере и ограничены его квотой хранения. Для каталога на 8–9 тысяч товаров необходимы серверное хранение и импорт.

## Проверка

```sh
npx playwright install chromium
npm run build
npm test
```

Playwright автоматически запускает сервер предварительного просмотра на порту `4174`. Проверки охватывают мобильные и настольные сценарии: поиск и подбор, корзину, избранное, оформление заказа, изменение статуса, импорт прайсов и редактирование контента.

## Развёртывание

Проект настроен для Vercel: команда сборки `npm run build`, каталог публикации `dist`. Конфигурация находится в [vercel.json](vercel.json).

Для публикации через Vercel CLI из связанного с проектом каталога:

```sh
vercel deploy --prod
```

При размещении на собственном сервере необходимо настроить возврат `index.html` для клиентских маршрутов. Готовый пример — [конфигурация Nginx](docs/nginx.conf.example).

Индексация демоверсии отключена через `robots.txt` и заголовок `X-Robots-Tag`. Перед коммерческим запуском настройки индексации следует пересмотреть вместе с SEO-конфигурацией.
