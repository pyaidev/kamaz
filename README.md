# КАМДЕТАЛЬ — frontend интернет-магазина

Адаптивная концепция магазина запчастей для КАМАЗ по переписке с заказчиком celtik47. Временный бренд «КАМДЕТАЛЬ», русский интерфейс, промышленная визуальная концепция с крупной типографикой Oswald, тёмным первым экраном и оранжевыми акцентами. Данные демонстрационные: 15 товаров, 6 категорий. Архив factdb не использовался.

Онлайн: https://kamdetal-storefront.vercel.app/ · Панель: https://kamdetal-storefront.vercel.app/admin

Код: https://github.com/pyaidev/kamaz. Первая production-версия опубликована через Vercel CLI. Автоматическая связь с GitHub пока не включена: Vercel требует добавить GitHub в Login Connections владельца аккаунта. После подключения можно выполнить `vercel git connect https://github.com/pyaidev/kamaz.git` в папке проекта. Ручное обновление: `vercel deploy --prod`.

## Запуск

Требуется Node.js 20.19+ или совместимая более новая версия.

```sh
npm ci
npm run dev -- --port 4173
```

Магазин: http://127.0.0.1:4173/ · Админка: http://127.0.0.1:4173/admin

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` — готовая сборка. Сервер должен отдавать `index.html` для неизвестных путей (SPA fallback). Пример настройки: `docs/nginx.conf.example`.

## Что реализовано

- Главная: кинематографический первый экран с прозрачным WebP грузовика, крупные анимированные заголовки, движущаяся типографическая лента, категории и подборки товаров.
- Подбор: вкладки поиска по артикулу, модели + группе и VIN с переносом номера в заявку.
- Движение: появление блоков при прокрутке, реакция изображения на указатель, полёт товара к корзине, состояния кнопок, анимированная техническая схема, прогресс прокрутки и возврат наверх. Настройка reduced motion отключает эффекты.
- Каталог: категории и подкатегории, поиск по названию / артикулу / OEM / производителю, нормализация пробелов и разделителей, фильтры наличия / цены / модели / бренда, сортировка, плитка / список, дозагрузка.
- Карточка товара: галерея, характеристики, применяемость, количество, корзина, избранное, форма покупки в один клик, вкладки доставки и гарантии.
- Корзина: изменение количества, удаление, пересчёт, сохранение при перезагрузке.
- Оформление: организация / ИП / физлицо, реквизиты, СДЭК до ПВЗ / курьер / самовывоз, пример тарифа, комментарий, согласие, сохранение демо-заказа.
- Кабинет: история заказов, статусы, детали, печать состава заказа, редактирование профиля.
- Админка: статистика, поиск и редактирование товаров, обработка заказов, импорт CSV / XLSX с предварительной проверкой, редактирование заголовков и баннера, загрузка изображения главной до 1 МБ.
- Информационные страницы: доставка / оплата, гарантия / возврат, о компании, контакты, локальное хранение данных.
- Мобильная навигация, адаптивные сетки, диалоги, состояния пустого каталога и корзины, сообщения об ошибках.
- Динамические title / description, демонстрационная разметка Product и BreadcrumbList. `noindex` и запрет обхода оставлены намеренно.

## Границы демоверсии

Это frontend, а не готовый backend-магазин. LocalStorage заменяет сервер только для просмотра сценариев. Настоящая авторизация, защищённая админка, БД, счёт с реквизитами продавца, подтверждение оплаты, API поставщика, СДЭК, отправка уведомлений и серверный SEO не подключены. Пример тарифа не является тарифом СДЭК; печать заказа не является счётом на оплату.

Импорт читает до 15 000 строк / 10 МБ, но сохранение ограничено квотой браузера. Для реальных 8–9 тысяч товаров нужны база данных, серверная пагинация и фоновый импорт. При нехватке места импорт показывает ошибку и не применяет изменения. Не добавляйте реальные персональные данные в публичную демоверсию.

Изменения сохраняются только в текущем браузере. Очистка данных сайта сбрасывает демонстрацию. Панель `/admin` доступна без пароля именно как прототип.

## Формат импорта

Образец: `public/price-template.csv`. Обязательные колонки: `Артикул`, `Название`, `Цена`, `Остаток`, `Производитель`. Необязательная: `Категория`. Поддержаны английские имена `article`, `name`, `price`, `stock`, `brand`, `category`. CSV в UTF-8, разделитель определяется автоматически; Excel — `.xlsx`, первый лист. Артикулы с ведущими нулями следует хранить как текст.

Ключ обновления — нормализованные артикул + производитель. Проверяются дубликаты, положительная цена и целый неотрицательный остаток. Пока есть ошибки, применение заблокировано. Товары, отсутствующие в файле, не изменяются. Новая позиция получает иллюстрацию категории и требует уточнения характеристик; неизвестная категория отклоняется. При отсутствии категории новая позиция попадает в «Двигатель», а существующая сохраняет свою категорию.

## Проверка

```sh
npm run build
npm test
```

Playwright запускает production preview на порту 4174. При отсутствии браузера: `npx playwright install chromium`. Тесты проверяют ключевые страницы на desktop / mobile, поиск, корзину и избранное после перезагрузки, оформление и смену статуса, CSV / XLSX импорт, редактирование главной и однокликовую заявку.

## Файлы

- `src/data.ts` — типы, категории, демо-товары.
- `src/store.tsx` — состояние приложения и адаптер локального сохранения.
- `src/components.tsx` — навигация, карточки, формы, общие компоненты.
- `src/home.tsx` — главная и интерактивный подбор.
- `src/pages.tsx` — каталог, товар, избранное.
- `src/motion.tsx` — анимации появления, прокрутки и добавления в корзину.
- `src/commerce.tsx` — корзина, оформление, кабинет, заказ.
- `src/admin.tsx` — административная панель, загружается отдельно.
- `src/seo.tsx` — метаданные и структурированные данные.
- `src/styles.css`, `src/readability.css`, `src/premium.css` — адаптивный дизайн и новая визуальная система.
- `docs/research.md` — разбор конкурентов и решения.
- `docs/backend-handoff.md` — задачи подключения Laravel.
- `docs/home-desktop.png`, `docs/home-mobile.png` — снимки интерфейса.

Фото деталей взяты с kam.ru как временные иллюстрации прототипа: точные URL в `docs/asset-sources.txt`. Для коммерческого запуска заменить на материалы поставщика с разрешением на использование. Основное изображение создано через imagegen, оригинал в `docs/source/`. Шрифты Manrope и Oswald локальные, лицензии SIL OFL; иконки Lucide, ISC.
