# Подключение Laravel

Frontend React / TypeScript можно разместить рядом с Laravel и подключить к JSON API либо перенести компоненты в Inertia. Сейчас все операции выполняются локально в `StoreProvider`; рабочих HTTP-интеграций нет.

| Область | Предлагаемый интерфейс сервера | Требования |
|---|---|---|
| Каталог | `GET /api/products`, `GET /api/products/{id}`, `GET /api/categories` | Фильтры, пагинация, нормализованный поиск, цена и остаток из БД. |
| Кабинет | `/api/auth/*`, `GET/PATCH /api/profile` | Реальная регистрация/вход, восстановление доступа, сессии и разграничение данных. |
| Заказы | `POST /api/orders`, `GET /api/orders/{id}` | Пересчёт на сервере, проверка остатков, идемпотентность, менеджерское подтверждение. |
| Счёт | `GET /api/orders/{id}/invoice` | Создавать после согласованного события; реквизиты продавца, юридически корректный номер и шаблон, только разрешённым пользователям. |
| СДЭК | `GET /api/delivery/points`, `POST /api/delivery/quote` | Ключи только на сервере; фактический отправитель, вес, упаковка, габариты и актуальный тариф. |
| Заявки | `POST /api/requests` | Валидация, ограничение частоты, сохранение и уведомление менеджера. |
| Импорт | `POST /api/admin/imports`, `GET /api/admin/imports/{id}` | Фоновая очередь, preview, отчёт об ошибках, транзакционное применение, журнал. |
| Управление | `/api/admin/products`, `/api/admin/orders`, `/api/admin/content` | Авторизация, роли и контроль изменений. |
| Медиа | `POST /api/admin/media` | Проверка MIME / размера, хранение и оптимизация изображений. |

Для 8–9 тысяч позиций не передавать весь каталог клиенту. Индексировать артикулы, OEM, производителя, категорию; изображения грузить по мере необходимости. При импорте ключом служит согласованный идентификатор поставщика либо связка производителя и артикула. Заранее определить, что означает отсутствие строки в новом прайсе.

Публичные каталог и товары требуют серверного HTML или согласованного SSR/prerender. Перед индексированием подключить реальный домен, canonical, sitemap, корректные Product / Offer и BreadcrumbList; наполнить реальные данные и заменить демонстрационный robots/noindex. Успешная SPA-сборка сама по себе не означает готовность SEO и не гарантирует зелёный PageSpeed.

Данные профиля и заказов нужно убрать из localStorage при переходе к реальному аккаунту. Цена, доставка, налоги и доступность проверяются сервером; клиентским значениям нельзя доверять. Админку нельзя запускать в текущем открытом виде с настоящими данными.
